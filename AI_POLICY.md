# AI Policy

Use AI. We do.

- **AI-written code is welcome.** So are AI-written issues, pull request
  descriptions and review replies.
- **You're responsible for what you send.** Make sure it builds, the tests
  pass, and it does what the description says.
- **Mention the model if you like.** It helps reviewers, but it's not a
  requirement and it never counts against a contribution.
- **No bulk spam.** One focused change per pull request, same as for any
  contributor.

We judge contributions by whether they're correct, tested and maintainable,
not by who or what typed them.
